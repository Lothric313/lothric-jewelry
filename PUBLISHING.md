# Lothric — GitHub Pages

Статический демонстрационный сайт ювелирного бренда Lothric.

В репозитории находятся HTML, CSS, JavaScript, используемые изображения,
шрифты с лицензией и настройка GitHub Pages. Локальные инструменты,
исходные варианты изображений, история генерации и материалы проверок
сохраняются только в рабочей папке и исключены через `.gitignore`.

Публикация: **Settings → Pages → Source → GitHub Actions**.
Workflow `.github/workflows/deploy-pages.yml` проверяет синтаксис JavaScript,
собирает статические файлы и публикует сайт при изменении ветки `main`.
Повторный запуск: **Actions → Deploy GitHub Pages → Run workflow**.

После первого развёртывания сайт будет доступен по адресу
https://lothric313.github.io/lothric-jewelry/.

Серверная часть не требуется. Каталог, анимации и корзина работают
в браузере. Корзина сохраняется локально. Цены и контакты демонстрационные;
оплата и отправка формы не подключены.
